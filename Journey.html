About My Project

I build robots and websites that have the potential to help the world. I took the initiative to create a website after noticing that our school lacked a dedicated sports portal. I pitched this idea to my DTI teacher as part of my worksheet project.

Target Audience: Students and teachers.

Goal: Help students stay informed and prepared for upcoming game matches, while allowing teachers and organizers to announce events with automatic student notifications.

Questions & Answers

1. Did your website meet its original purpose?

Yes, it met its original purpose and has strong potential to improve even more in the future.

2. Which part of your website works best?

The <script> tag works best. Even though it was not required in the worksheet, it acts like a function (similar to CodeMonkey) and allows me to add scripts that change how the website behaves—such as playing background music on a loop.

3. What problems did you face while creating the website?

My biggest challenges were image positioning using the <img> tag, adding background audio using the <audio> tag, and overall layout design. Since CSS was not allowed, making the site look good using only plain HTML tags like <table>, <br>, and formatting was difficult, so I relied on online tutorials and courses to build it effectively.

4. What improvements would you make if you had more time?

If I have more time, what I can improve is my design, functionality, and system architecture. Because I don't know how well it can function once launched on the internet, and right now the layout looks very simple, refining the visual appearance without CSS and ensuring smooth server interaction are my primary targets for future updates.
